# Republic Documentation Root

Republic is a **persistent multiplayer political and nation-building simulation**.

Every player governs their own procedurally generated country in a shared, living geopolitical world with the primary objective:

> **BUILD, STRENGTHEN, PROTECT AND SUSTAIN THEIR COUNTRY.**

## Core System Highlights

1. **The Country as the Central Simulation Object**: The entire nation lives and endures; the Presidential Office serves as the executive command interface.
2. **Foundational Multiplayer Reality**: Diplomacy, bilateral trade, treaties, alliances, intelligence, economic rivalry, and conflict between sovereign player countries.
3. **Official Currency — REPU (`R`)**: Denominated in REPU (e.g., `R45M`, `R450M`, `R1.2B`).
4. **National Yield & State Capacity**: Measurable output and institutional capacity of a functioning state (14 categories).
5. **Emergent Food Economy**: Public enabling environment investments driving private agricultural production.
6. **Real-World Global Clock**: Aligned with the Gregorian calendar in **West Africa Time (WAT / UTC+1)**, advancing continuously from **Republic Day 0, 00:00 WAT**.
7. **Continuous Offline Persistence**: *"Revenue is continuous. Development is continuous. Politics is continuous. The player is not."*
