# ADR-0019: Readable Sovereign Country Profile

## Status
Accepted

## Context
Following the establishment of the sovereign country naming rule ([ADR-0018](ADR-0018-country-naming-rule.md)), Phase 5 item 5.1 introduces a human-readable **Country Profile** stored directly on the sovereign country entity.

Prior to this decision, a nation possessed numerical simulation states (treasuries, capacity factors, cabinet portfolios, yield balances), but lacked a structured, human-readable profile describing its constitutional form, regional geography, demographics, capital city, dominant language, primary natural resource, and political culture.

## Decision

1. **Immutable CountryProfile Value Object**:
   - Implemented as [`CountryProfile`](../../../src/Republic.Core/World/Models/CountryProfile.cs).
   - Records ten authoritative descriptive attributes:
     - `OfficialName`: Legal ceremonial title of the sovereign state. Must pass the whole-word "Republic" validation rule ([ADR-0018](ADR-0018-country-naming-rule.md)).
     - `Capital`: Seat of government and administrative capital.
     - `Region`: Sovereign macro-region represented by enum [`CountryRegion`](../../../src/Republic.Core/World/Models/CountryProfile.cs) (`West`, `East`, `Central`, `North`, `South`).
     - `Population`: Non-negative national population count (`long`). Negative population values are strictly rejected with an exception.
     - `DominantLanguage`: Primary language spoken across civic society.
     - `GovernmentForm`: Constitutional form represented by enum [`GovernmentForm`](../../../src/Republic.Core/World/Models/CountryProfile.cs) (`Republic`, `Parliamentary`, `Federal`, `Military`).
     - `ConstitutionName`: Official title of the nation's supreme basic law or constitution.
     - `PrimaryResource`: Primary natural resource anchor of the domestic economy.
     - `PoliticalCulture`: Single-sentence summary of the nation's political tradition and civic ethos.
     - `FoundingTime`: The authoritative [`RepublicTime`](../../../src/Republic.Core/Time/RepublicTime.cs) simulation founding moment already present on the sovereign country entity. Reuses the existing timestamp without creating a duplicate founding date.
   - Missing string properties default strictly to `"Unspecified"`, never `null`.

2. **Attachment to Sovereign Country Model**:
   - Attached as a first-class property on [`Country.Profile`](../../../src/Republic.Core/World/Models/Country.cs).
   - Preserves all existing country fields, collections, and simulation engines without breaking changes.
   - Reading a profile is strictly side-effect-free: inspecting Country A's profile does not mutate its treasury balance, nor does it affect Country B.

3. **Arcadia Fixed Defaults and Stability**:
   - Arcadia preserves its existing `Id`, `Treasury`, and `FoundingTime`.
   - If Arcadia's name already contains `"Republic"`, it is retained; otherwise, it is initialized to `"Republic of Arcadia"`.
   - Populated with fixed, canonical defaults (`Grand Arcadia`, `Central`, `10,000,000`, `English`, `Federal`, `Constitution of the Republic of Arcadia`, `Iron`) without random generation.

4. **Seeded Deterministic Profile Factory**:
   - Defined via contract [`ICountryProfileFactory`](../../../src/Republic.Core/World/Factories/ICountryProfileFactory.cs) and implemented by [`CountryProfileFactory`](../../../src/Republic.Core/World/Factories/CountryProfileFactory.cs).
   - New countries generated by the factory receive deterministic attributes generated exclusively from an integer seed (`new Random(seed)`).
   - The same seed produces identical profiles across runs.
   - Purity rules: Unseeded random calls and ambient system clock accesses (`DateTime.Now`) are strictly prohibited.
   - The factory explicitly calls [`CountryNameRule`](../../../src/Republic.Core/World/Rules/CountryNameRule.cs); any generated name failing the rule results in a test failure, not a silent rewrite.

5. **CLI Dashboard Integration**:
   - Rendered directly on the presidential desktop in [`Program.cs`](../../../src/Republic.Cli/Program.cs) immediately beneath the liquid treasury line.
   - Formats the official name, capital, region, population, government form, and primary resource.
   - Preserves the existing top-level CLI executive menu without introducing new menu numbers.

6. **Scope Boundary**:
   - Constrained strictly to Phase 5 item 5.1 (Readable Country Profile).
   - Does not implement 5.2 dashboard scores, 5.3 national strength, 5.4 consequences, elections, or networking.

## Consequences
- Players and simulation observers can read comprehensive constitutional and geopolitical profiles of any sovereign state.
- Profile generation is 100% deterministic and reproducible via seeds.
- The whole-word "Republic" naming constraint is enforced across all profile construction and factory generation pipelines.
